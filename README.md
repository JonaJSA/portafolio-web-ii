# Portafolio Web II

Portafolio académico de **Jonathan Ávila**, desarrollado como proyecto para la asignatura Portales Web II.

## Enlaces

- Sitio publicado: <https://jonajsa.github.io/portafolio-web-ii/>
- Repositorio: <https://github.com/JonaJSA/portafolio-web-ii>
- Perfil de GitHub: <https://github.com/JonaJSA>

## Características

- HTML5 semántico y accesible.
- Diseño adaptable para computadora, tableta y teléfono.
- Modo claro y oscuro con preferencia guardada en el navegador.
- Filtros interactivos para los proyectos.
- Animaciones de entrada y efecto de texto dinámico.
- Indicador de progreso de lectura.
- Respeto a la configuración `prefers-reduced-motion`.
- Metadatos, favicon y navegación mediante teclado.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git y GitHub Pages

## Uso local

Puede abrir `index.html` directamente en el navegador o iniciar un servidor local:

```bash
python -m http.server 5500
```

Luego visite `http://localhost:5500`.
